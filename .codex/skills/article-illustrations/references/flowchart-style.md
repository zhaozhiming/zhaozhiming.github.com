# Excalidraw 风格流程图规范

## 目标

创建准确、简洁、可编辑的中英文 SVG 流程图，帮助读者理解步骤、架构、数据流、关系或生命周期。程序化绘制 SVG，不使用图片生成模型。先完成中文版，再复制为英文版并只翻译文字。最终保留双语 SVG，并使用 `prepare-illustration.sh` 生成对应 JPG。

## 确认 Gate 中的绘图方案

在创建正式 SVG 前，向用户展示：

```text
标题：<流程图标题>
布局：<从左到右 / 从上到下 / 中心辐射 / 分区>
节点：<节点列表及每个节点的短文字>
连线：<起点、终点、方向和连线含义>
分组：<可选的边界或阶段>
颜色含义：<每种强调色代表什么>
英文文字方案：<标题、节点、条件和辅助标签的英文翻译>
```

用户确认后，不得擅自增加、删除或改变节点、连线及其含义，也不得改变英文版的布局结构。

## 双语一致性

- 中文版文件使用 `<article-slug>-<topic>.svg`，英文版使用 `<article-slug>-<topic>-en.svg`。
- 先完成并验证中文版 SVG，再复制创建英文版 SVG。
- 英文版只翻译 `<text>` 元素中的可见文字。
- 英文版不得改变任何图形元素、节点数量、连线、箭头、颜色、分组、坐标、尺寸、路径数据或画布。
- 英文文字较长时，优先使用更短且含义准确的英文表达；必要时只允许调整对应 `<text>` 元素的 `font-size`，不得移动节点或改变布局。
- 产品名、技术标识、文件名和路径保持原文，例如 `Plugin`、`plugin.json`、`.mcp.json`。

## 画布与布局

- 使用 `1600x900` SVG 画布和 `viewBox="0 0 1600 900"`。
- 使用浅色背景，优先选择 `#fffdf8` 或白色。
- 四周至少保留 80 px 留白，节点之间至少保留 60 px。
- 标题不超过一行；节点文字不超过两行；节点总数通常为 3～8 个。
- 优先使用从左到右或从上到下布局。只有关系网络确实需要时才使用中心辐射或分区布局。
- 连线不得穿过节点文字；交叉连线应尽量避免。

## Excalidraw 风格

- 使用圆角矩形、椭圆、简化图标、弯曲箭头和分组区域。
- 使用深灰轮廓，推荐 `#1f2937`，线宽通常为 4～6 px。
- 使用 `stroke-linecap="round"` 和 `stroke-linejoin="round"`。
- 可使用轻微不规则的双路径、偏移轮廓或弧线模拟手绘感，但不得牺牲连线准确性。
- 节点填充限定为浅蓝 `#dbeafe`、浅绿 `#dcfce7`、浅黄 `#fef3c7`、浅紫 `#ede9fe` 和浅红 `#fee2e2`。
- 同一语义类型使用同一颜色。颜色只用于分组和强调，不用于装饰。
- 不使用阴影、渐变、逼真材质、照片或复杂插画。

## 文字规则

- 中文版使用中文和准确术语；英文版使用准确英文翻译。
- 中文字体使用 `PingFang SC, Microsoft YaHei, sans-serif`；英文可使用 `Arial, sans-serif`。
- 标题建议为 44～56 px，节点文字建议为 28～38 px，辅助标签建议为 22～28 px。
- 每个节点使用短语而非段落。需要补充说明时，放到节点下方的短标签中。
- 不使用 SVG `foreignObject`，确保 `rsvg-convert` 可稳定渲染。

## 连线与箭头

- 每条连线必须有明确起点、终点和方向。
- 使用 `<path>` 绘制直线或曲线；箭头可使用 `marker-end` 或独立箭头路径。
- 双向关系必须使用双箭头或两条方向明确的连线。
- 条件分支必须标注简短条件。
- 数据流、控制流和依赖关系不能用同一条无标签连线混合表达。

## 推荐 SVG 骨架

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="1600" height="900" viewBox="0 0 1600 900">
  <rect width="1600" height="900" fill="#fffdf8"/>
  <defs>
    <marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5"
      markerWidth="8" markerHeight="8" orient="auto-start-reverse">
      <path d="M 0 0 L 10 5 L 0 10 z" fill="#1f2937"/>
    </marker>
  </defs>
  <!-- Add groups, nodes, labels, and directional paths here. -->
</svg>
```

## 创建与验证

1. 根据已确认绘图方案，使用 `apply_patch` 直接创建中文 SVG。
2. 复制中文 SVG 为 `-en.svg`，只翻译可见文字。
3. 检查中英文所有节点文字、连线方向、条件标签和颜色含义。
4. 对比双语 SVG，确认除 `<text>` 内容及必要的文字字号外，所有结构属性一致。
5. 使用 `rsvg-convert` 或后处理脚本生成双语预览，确认没有文字截断或重叠。
6. 使用 `prepare-illustration.sh` 生成双语最终 JPG，并保留双语 SVG。
7. 验证双语 JPG 均为 16:9、严格小于 `307200` bytes，且缩小后仍可读。

任何文字、连线或布局错误都必须先修复对应 SVG，再重新生成 JPG；不得直接修改 JPG 掩盖源文件问题。英文版出现布局问题时，优先缩短翻译或调整文字字号，不得改变图形结构。
